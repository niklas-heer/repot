# repot v0.2.0

This release makes **repot** pleasant to use from a terminal: a status report
that shows what needs attention, a fuzzy picker that stays out of your way, and
command names that make sense on first contact. Homebrew installs now come from
the shared `niklas-heer/tap`.

## Highlights

- **Status you can read at a glance.** `repot status` and `repot sync` group
  checkouts by what they need: failed, needs review, ready to push, ready to
  update, and a compact per-owner summary of everything up to date. Each row
  shows the branch, commits behind (↓) or ahead (↑), and staged, modified,
  untracked and stashed work. The footer suggests the next step.
- **Live progress.** A spinner with a counter shows fetching, cloning and
  updating as it happens.
- **An inline picker.** `repot cd` opens directly under your prompt instead of
  taking over the screen, so the output you were reading stays visible. It is
  never taller than the results and erases itself when you are done.
- **Commands named for what you want to do.** `cd` jumps to a repository,
  `clone` clones, `new owner/name` creates an empty repository in the tree next to
  `new name` for scratch projects, and `scan` finds strays. Run `repot --help`
  for a task-grouped overview with the version and a small logo.
- **Clearer failures.** Errors say what went wrong and what to try next, and
  mistyped commands or options get a suggestion.
- **Nushell works like the other shells.** The wrapper no longer captures
  repot's output, which previously forced the plain script format and hid all
  progress. Report commands can be piped: `repot status --json | from json`.

## Compatibility

Every earlier command name keeps working: `jump`, `get`, `find`, and the hidden
`create` and `migrate`. `--json` output and the tab-separated piped format are
unchanged, as are the MCP tool names. `status` and `sync` now inspect eight
repositories at a time by default instead of four; `--jobs` still overrides it.

## Install

```sh
brew install niklas-heer/tap/repot
```

If you installed from the former `niklas-heer/repot` tap, `brew update` moves
repot to the shared tap; afterwards run `brew untap niklas-heer/repot`.

Or build the pinned release through Nix:

```sh
nix profile install github:niklas-heer/repot/v0.2.0
```

Release archives cover macOS and Linux on x86-64 and ARM64; verify them against
`SHA256SUMS`. After upgrading, restart your shell or re-source the output of
`repot shell-init` so the new wrapper is active.

See the [installation guide](https://github.com/niklas-heer/repot/blob/v0.2.0/docs/install.md)
and the [user guide](https://github.com/niklas-heer/repot/blob/v0.2.0/docs/guide.md).
