# repot v0.4.0

This release makes **repot** faster on many checkouts, dependable in every
supported shell, and easier to point at just the repositories you mean.

## Highlights

- **A third of the Git processes.** Cached status reads a clean checkout with 4
  Git processes instead of 14: one `git status --porcelain=v2` call replaces
  separate reads of HEAD, upstream, stashes and changes, and the default branch
  comes from the cached `origin/HEAD`. On 100 clean clones, `repot status
  --no-fetch` went from 2.47 s to 0.76 s, and from 6.48 s to 1.62 s with
  `--jobs 1`. Safety checks and every change `sync` makes still go through the
  Git CLI. A test now holds repot to this budget.
- **Every shell, tested.** Bash, zsh, fish and Nushell integrations are safe to
  source again without stacking hooks, and CI now runs all four on Linux and
  macOS without skipping any.
  - Nushell: loading completions no longer breaks `repot cd`, exit codes are
    current, output can be captured, and directory symlinks are followed. Your
    own `PWD` hooks survive reloading the integration.
  - Bash keeps the previous command's exit code for your prompt and accepts an
    array `PROMPT_COMMAND`; fish's `cd -` works after a jump.
- **Tab completion of repository names** for `cd`, `info`, `open` and `rm` in
  all four shells (and `jump` in Nushell).
- **Work on a selection.** `repot status` and `repot sync` take optional queries:
  `repot sync .` updates only the checkout you are in, and `repot status alpha`
  only the repositories matching `alpha`. Unselected checkouts are never fetched.
- **Calmer reports.** Names are sorted naturally, so `repo2` comes before
  `repo10`, and a long **Up to date** group shows a short preview; `--verbose`
  lists all of them.
- **`repot cd owner/name`** jumps straight to an exact path instead of fuzzy
  matching.
- **`repot doctor --fix --dry-run`** shows planned fixes and skips without
  changing anything. Doctor now sees unpushed commits on every local branch, not
  only the current one.

## Fixes

- `repot info` no longer shows tokens or passwords from remote URLs, including
  ones hidden in query strings, fragments or user information.
- Stashes are counted on Git older than 2.35.
- `repot open` understands quoting in `REPOT_EDITOR`, `VISUAL` and `EDITOR`, so
  an editor path with spaces works, and branch names containing `#` open the
  right page on the web.
- A branch that shares its name with a tag now finds its upstream.
- Commands repot starts no longer inherit its shell handoff file.

## Compatibility

JSON output, exit codes and command names are unchanged, apart from `status` and
`sync` exiting `2` when a query matches no repository.

- **Nushell:** only the commands that change directory (`cd`, `jump`, `clone`,
  `new`, `adopt` and the like) are wrapped; everything else runs repot directly.
  Put global options after the subcommand, as in `repot cd --manifest PATH
  query`. Read status exit code 3 with `repot status --json | complete`.
- **`repot doctor --fix --yes`** now relocates misplaced checkouts that have
  local work, moving the work along. It still never archives a checkout with
  unique work.

## Install

```sh
brew install niklas-heer/tap/repot
```

Or build the pinned release through Nix:

```sh
nix profile install github:niklas-heer/repot/v0.4.0
```

Release archives cover macOS and Linux on x86-64 and ARM64; verify them against
`SHA256SUMS`. After upgrading, regenerate your shell integration and completions
(see the [installation guide](https://github.com/niklas-heer/repot/blob/v0.4.0/docs/install.md))
and restart your shell.

See the [user guide](https://github.com/niklas-heer/repot/blob/v0.4.0/docs/guide.md).
